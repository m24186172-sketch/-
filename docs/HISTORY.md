# سجل المحادثة والقرارات (بالترتيب)

ملخص كامل لمحادثة بناء الموقع، عشان أي جلسة جديدة تعرف ليش كل شي صار كذا.

## البداية (2026-11-10)
1. **الطلب الأول**: موقع مسابقات «نفس من أنا اللي سويناها»، بدون نقاط، وأقترح ألعاباً وأسأله.
2. اختار المستخدم: من أنا، لا تقول الكلمة، رتّب الحروف، كمّل المثل، حزّر العلم/الدولة، سين جيم. وطريقة اللعب **شاشة وحدة للقروب**. والمحتوى: **دين وصحابة وتاريخ وعلماء بأي نوع علم، وعام، وجغرافيا**.
3. بُنيت النسخة الأولى (6 ألعاب) ونُشرت Artifact.

## تعديلات الليلة الأولى
4. «شل سين جيم وحط مثل جملة مشهورة كلام مشهور بدون نقاط، وزد الأسئلة، وغيّر القوائم» → فُهمت خطأً وصارت لعبة «مين قالها؟»، واستُبدلت كل القوائم بمحتوى جديد أكثر.
5. المستخدم صحّح: «بدون نقاط» **اسم لعبة سويناها**. فصارت لعبة «بدون نقاط»: نص مشهور مكتوب بلا نقاط، تُحذف نقاطه برمجياً، وحلّت محل «مين قالها؟». بياناتها = `QUOTES` + `PHRASES`.
6. «شل رتّب الحروف وحط حروف مع وناسة، وغيّر ألوان القوائم» → لعبة **حروف** (لوحة سداسية بفريقين، مثل برنامج حروف)، ومربعات ملونة.
7. سأل كيف يرسل الموقع، فشُرحت له المشاركة من زر Share.

## اليوم الثاني (2026-11-11)
8. «أبي بنك أسئلة، وإذا فتحت السؤال ما يجيني مرة ثانية» → أُضيف بنك الأسئلة ومنع التكرار.
9. الرابط القديم صار عاماً فلم يعد قابلاً للتعديل من جلسة الوكيل → **رابط جديد** (BfjfdKa…).
10. سأل: هل الإجابات موثوقة؟ → شُرح ما فيه خلاف: طول النيل، بحر قزوين، ومقولات نسبتها غير مؤكدة.
11. **قرار محوري**: «ما أبي الأسئلة تتكرر لو طلعت مع أخوياي، مع أهلي، مع عمي، مع خوالي... أبي كل شوي يتجدد» → حفظ «اللي انفتح» في `db` على حساب المستخدم، وتوليد أسئلة جديدة بلا نهاية عبر `sample`، لكل الألعاب.
12. «بنك الأسئلة ما أبيه بالأرقام، أبيها ورا بعض وعشوائية: مرة دين مرة عام مرة جغرافيا... وصعّبها شوي» → صار البنك تسلسلاً عشوائياً واستُبدلت أسئلته بأصعب.
13. «حط زر التالي أو تخطّى إذا ما بغيت السؤال» → زر «تخطّى ⏭» في كل الألعاب.
14. «زد عدد بنك الأسئلة» ثم «أكثر شي تزيده الأسئلة الدينية» → زيادة كبيرة، والتوليد المختلط نصفه ديني.
15. سأل: هل الرابط القديم يشمل التعديلات؟ → لا، والجديد فيه كل شي.
16. أرسل **شعار مجمع حلقات جامع محمد بن سلطان**: «خلّ قوائم الموقع نفس الشعار، واسمه **ثقافي السلطان**» → هوية كحلي وأزرق. والرابط السابق كان قد صار عاماً → **رابط ثالث** (B5Wd7YNS…، الحالي).
17. «خلها أفضل» ثم «أفضل أكثر» → واجهة بقوس محراب ونقشة، أيقونات SVG، خطوط كوفية، حركات، مؤقت دائري، قصاصات فوز، زر ملء شاشة.
18. «زد الأسئلة، مو سهلة، متوسطة أو صعبة، في كل الكاتيجوريات».
19. اشتكى من كثرة الروابط الجديدة → شُرحت الحلول (التعديل من claude.ai/Claude Code على نفس الرابط العام، أو المشاركة بالإيميل، أو GitHub Pages). وافق على الحل الأول.
20. «الصورة اللي عليها جامع السلطان وراها شكل مربع مخرب، شيله» → صار الشعار PNG بخلفية شفافة.
21. طلب لعبة جديدة فيها أسئلة («زي ألعاب فالكونز في اليوتيوب، فيها أوراق»)، ورفض «برّا السالفة» → أُضيفت **اسحب ورقة** و**اذكر وتكشف**.
22. «الأسئلة مرة بيسك، صعّبها» → حُذفت الأسئلة السهلة والقوائم البديهية وأُضيفت أصعب، وشُدّد التوليد على «صعب».
23. «لا أشياء كورة كذا ما تحطها» → حُذفت أسئلة الرياضة كلها، ومُنعت في التوليد.
24. نقل المشروع إلى Claude Code (هذا الملف).

## أمور معلّقة
- المستخدم قال إن عنده «شي مهم» بيقوله بعدين، ولم يقله بعد.
- ما زال ما تأكد إن التعديل على الرابط العام من claude.ai أو Claude Code يشتغل فعلاً.
